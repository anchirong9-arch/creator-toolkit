# 🧰 올인원 크리에이터 툴킷

사진·PDF·링크·문서를 다루는 **8가지 도구**를 한 곳에 모은 웹 툴킷입니다.
모든 처리는 **브라우저(내 폰) 안에서만** 이루어지고, 파일은 서버로 전송되지 않습니다.

👉 **바로 쓰기: https://anchirong9-arch.github.io/creator-toolkit/**
👉 **엑셀 · PPT 편집기: https://anchirong9-arch.github.io/creator-toolkit/office.html**

폰 브라우저에서 열고 **홈 화면에 추가**하면 주소창 없는 앱처럼 실행됩니다(PWA, 오프라인 동작).

## 8가지 도구

| # | 도구 | 하는 일 |
|---|------|---------|
| ① | **EXIF 제거 · 모자이크** | 사진을 캔버스로 다시 그려 GPS·기기·촬영시각 등 EXIF를 완전 제거. 손가락으로 문질러 모자이크/블러 → PNG·JPG 저장 |
| ② | **URL 추적 제거** | 인스타(`igsh`, `lqvp`, `bqrl`, `hvrq`, `fqnt`)·스레드·쿠팡·유튜브·네이버 링크에서 `utm_*`, `fbclid`, `gclid`, `si` 등 추적 값만 제거. 여러 개 한 번에, 원클릭 복사 |
| ③ | **PDF ↔ 이미지** | PDF 각 페이지를 JPG/PNG로 풀기(페이지 범위·해상도 선택, 개별/일괄 ZIP), 이미지 여러 장을 PDF 1개로 묶기 |
| ④ | **이미지 압축 · 포맷 변환** | 여러 장 일괄 압축 + JPG/PNG/WebP 변환, 전후 용량·절감률 비교, ZIP 저장 |
| ⑤ | **QR 생성기** | 링크·텍스트·와이파이(SSID·비번) → 만료 없는 순수 QR PNG(512/1024/2048px) |
| ⑥ | **비율 리사이즈** | 1:1 · 4:5 · 9:16 · 16:9로 안 잘리게 맞추고 여백은 흰색·검정·블러로 채우기 |
| ⑦ | **일괄 워터마크** | 여러 장에 문구(`@uhaeham`, `@animallolvillage` 프리셋) 또는 로고를 위치·투명도·크기 조절해 한 번에 |
| ⑧ | **엑셀 · PPT 편집기** | 오피스 없이 `.xlsx`·`.xlsb`·`.xls`·`.csv`·`.pptx`를 열어 표·슬라이드 **미리보기** 후 그 자리에서 편집. 셀 수식·행/열·시트 관리, PPT 텍스트 수정·순서·복제, **슬라이드 이미지 일괄 압축**, `.xlsx`·`.csv`·`.pptx` 저장 (`office.html`) |

## 구조

```
index.html            앱 셸 (탭 라우팅은 해시: #/exif, #/url …)
office.html           엑셀 · PPT 편집기 페이지 (탭에서 이동)
css/app.css           다크 모바일 UI
css/office.css        편집기 UI (같은 팔레트)
js/app.js             라우터 · 공용 UI · ZIP(무압축) 생성 · 이미지 유틸
js/tools/*.js         도구 8종 (각각 독립 모듈, office.js는 office.html로 연결)
js/office/excel.js    엑셀 그리드 엔진 (SheetJS) — 읽기/편집/수식 복원/저장
js/office/pptx.js     PPT 엔진 (JSZip) — 슬라이드 렌더·텍스트 편집·이미지 압축/저장
js/office/app.js      편집기 화면 컨트롤러 (파일 열기·드래그앤드롭·저장)
lib/pdf.min.js        PDF 렌더링 (pdf.js 3.11)
lib/jspdf.umd.min.js  이미지 → PDF (jsPDF 2.5)
lib/qrcode.js         QR 매트릭스 생성 (qrcode-generator 1.4)
lib/xlsx.full.min.js  엑셀 읽기/쓰기 (SheetJS 0.20.3) — 엑셀을 열 때만 로드
lib/jszip.min.js      pptx 압축파일 처리 (JSZip 3.10.1)
office/blank.pptx     '새 파워포인트'용 빈 템플릿
manifest.json, sw.js  PWA(설치·오프라인)
icons/                앱 아이콘(PIL 스크립트 포함)
```

라이브러리는 CDN이 아니라 저장소에 포함되어 있어 **인터넷이 끊겨도** 동작합니다.

## 개인정보

- 업로드한 사진·PDF·링크는 어떤 서버로도 전송되지 않습니다(네트워크 요청 없음).
- 저장 파일은 기기의 다운로드 폴더로 바로 내려갑니다.
- EXIF 제거는 "캔버스에 다시 그린 뒤 저장" 방식이라 메타데이터가 남지 않습니다.
- 엑셀·PPT 파일도 브라우저 메모리에서만 열리고, 저장 파일은 기기의 다운로드 폴더로 바로 내려갑니다. 서버 업로드가 없어 사내 문서도 안심하고 다룰 수 있습니다.

## 엑셀 · PPT 편집기 메모

- **엑셀**: 열면 시트 표가 바로 보이고(열 폭 자동, 머리글 강조) 셀 클릭으로 편집합니다. 수식은 그대로 보존되며 계산은 엑셀에서 열 때 이뤄집니다. `.xlsb`로 열어도 `.xlsx`로 저장됩니다.
- **PPT**: 썸네일 + 현재 슬라이드 캔버스(배경·텍스트 위치·내장 이미지)를 그리고, 텍스트 상자를 클릭/더블클릭해 고칩니다. XML의 `<a:t>` 글자만 바꿔 서식은 유지합니다.
- **이미지 압축**: 최대 해상도·JPEG 품질을 고르면 절감 예상치를 먼저 계산해 보여주고, 적용하면 `ppt/media/*` 파일을 실제로 줄입니다(투명 PNG는 PNG 유지, 나머지는 JPEG).
- 라이브러리는 저장소에 포함되어 있고, SheetJS는 엑셀을 처음 열 때만 내려받습니다.
